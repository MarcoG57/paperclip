# Encargo para la siguiente sesión de implementación

Trabaja en este fork. Lee `AGENTS.md`, `company/AGENTS.md`, `company/README.md` y `company/ROADMAP.md`. Inspecciona `git status` antes de modificar. No copies de repositorios privados al fork público.

Ejecuta las pruebas offline y revisa la CI del commit. El equipo ya se genera en el catálogo nativo; no crees otro harness, otro blueprint paralelo ni otra capa de persistencia. Elige el primer bloqueo de commissioning con inputs disponibles. Mantén models/efforts y no añadas API de pago, egress, agentes o plugins silenciosamente.

Usa hasta tres subagentes con archivos disjuntos. Solo la sesión principal aplica cambios compartidos. Si falta host, credencial, permiso o financiación, registra el bloqueo y completa el código/pruebas independientes. No rebajes el sandbox ni simules resultados para completar una casilla.

Cierra cada hito con: cambios, comandos/resultados, evidencias, lo no probado, riesgos y siguiente acción. Mantén cambios nativos pequeños y reproducibles. No declares una empresa funcionando por haber importado doce agentes.
